# ✨ 掌上造景贴纸小屋 (Sticker Diorama)

> 手机触控优化 · 沉浸式拟真贴纸书 · 解压微缩世界

基于 HTML5 + Canvas + Web Audio API 打造的在线拟真造景贴纸应用。真实还原线下手帐拼贴与场景贴纸书的撕贴体验。所有场景与贴纸素材均由 **Grok-2** 图像生成模型精心渲染。

📱 **在线畅玩体验地址**：[https://ygwbl.github.io/sticker-diorama/](https://ygwbl.github.io/sticker-diorama/)

## 🌟 核心特色与沉浸式体验升级

### 1. 极速丝滑的 60/120fps 触控手感
- **单指平滑拖拽**：采用 Pointer Capture 物理跟踪，彻底杜绝掉帧与边缘卡顿。
- **双指自然手势**：支持在屏幕上直接捏合缩放贴纸（Pinch to Zoom）与双指旋转。
- **右下角复合手柄 (🔄)**：专为单手操作设计的万向复合旋转缩放手柄，丝滑顺手。
- **拟真物理悬浮**：手指触碰撕起贴纸时，贴纸动态上浮倾斜并投下大光圈 3D 柔影，松手时伴随水润弹跳与 Pop 吸附音。

### 2. 沉浸式环境音效系统 (Web Audio 实时合成，零延迟免依赖)
- 🌧️ **雨声 (Gentle Rain)**：窗外淅淅沥沥的柔和雨丝声。
- 🪵 **壁炉 (Fireplace Crackle)**：温暖的冬日低频与柴火微响。
- 🎵 **Lofi 治愈和弦 (Lofi Chimes)**：优雅慢节奏的五声音阶电钢琴琶音，瞬间舒缓放松。
- 🔊 **动作 ASMR**：真实还原撕离型纸时的阻尼撕拉声、贴上的 Pop 音、旋转咔哒声与翻页沙沙声。

### 3. 动态光影与丁达尔微尘 (Tyndall Effect)
- 房间内漂浮着细腻的阳光微尘粒子，配合 6 大空间呈现温暖治愈的视觉层次。

### 4. 6 大精美微缩空间 (Grok-2 精绘)
- 🌅 **日落书房**：拱形大窗落日余晖、暖色实木地板。
- 🥖 **日式面包房**：阳光照射下的木质展架与刚出炉的面包香气。
- 🌿 **阳光温室**：整面玻璃花房窗景、晨光透射、陶土花砖。
- 🪵 **壁炉木屋**：雪夜窗景、温暖噼啪的石壁炉与柔和串灯。
- 🌺 **花房露台**：藤蔓垂挂的欧式花房与梦幻光斑。
- 🌙 **治愈猫窝**：满月飘窗、深蓝星夜与惬意地毯。

### 5. 🔮 Grok AI 贴纸工坊 (游戏内实时定制任何专属贴纸)
- 点击顶部「🔮 定制」，输入任意你想要的物品（如“草莓刨冰”、“戴礼帽的柯基”、“复古打字机”）。
- 前端自动调用 Grok-2 生成并实时运行智能 Flood-Fill 算法去除纯白背景，秒变专属透明贴纸，随心拼贴！
