# ✨ 掌上造景贴纸小屋 (Sticker Diorama)

> 手机触控优化 · 沉浸式拟真贴纸书 · 解压微缩世界

基于 HTML5 + Canvas + Web Audio API 打造的在线拟真造景贴纸应用。真实还原线下手帐拼贴与场景贴纸书的撕贴体验。所有场景与贴纸素材均由 **Grok-2** 图像生成模型精心渲染。

📱 **在线畅玩体验地址**：[https://ygwbl.github.io/sticker-diorama/](https://ygwbl.github.io/sticker-diorama/)

---

## 🌟 核心特色

1. **拟真撕贴 ASMR 音效与触控**
   - 纯算法实时合成（Web Audio API），还原撕开离型纸的阻尼感、贴上去的温润吸附声（Pop音）与旋转清脆咔哒声。
   - 移动端原生触感反馈（`navigator.vibrate`）。
2. **Grok AI 精绘微缩场景与贴纸**
   - 3 大治愈系空间：🌅 日落书房、🌿 阳光温室、🌙 治愈猫窝。
   - 丰富的高清免抠贴纸：复古软装、绿植花草、治愈猫狗萌宠、惬意生活微缩物件。
3. **针对手机拇指深度优化的操控手感**
   - **单指拖拽**：在房间内随意平移摆放。
   - **悬浮操作盘**：一键水平镜像翻转 (🪞)、图层上移/下移 (⬆️/⬇️)、角度微调 (↺/↻)、撕掉丢弃 (🗑️)。
4. **一键生成高清拍立得壁纸**
   - 点击右上角「保存」，通过离屏 Canvas 以 **2x 视网膜高清分辨率** 合成海报，可长按直接下载保存为手机锁屏壁纸。
5. **纯前端零依赖**
   - 无需后端服务、无广告打扰、秒级快速加载。

## 🚀 本地运行

双击 `index.html` 即可在任意现代浏览器中运行。推荐在浏览器开发者工具（F12）开启**移动端模拟模式**体验最佳效果。

如果想在局域网内用手机真机访问：
```bash
python -m http.server 8080
# 手机浏览器访问：http://<你的电脑内网IP>:8080
```
